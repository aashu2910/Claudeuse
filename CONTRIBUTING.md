# Contributing to Portfy Templates

Thanks for helping make free portfolios better for everyone.

## Ways to contribute

- **Report a bug** — open an issue with steps to reproduce and a screenshot if it's visual.
- **Suggest a feature** — open an issue describing the use case.
- **Submit a new template** — see below.
- **Improve accessibility or docs** — small pull requests are very welcome.

## Submitting a template

1. Fork the repo and create a branch: `git checkout -b template/your-template-name`.
2. Keep templates dependency-free (plain HTML, CSS and JavaScript).
3. Read all content from `profile.js` so users only edit one file.
4. Support light and dark mode and make sure it works at phone width.
5. Open a pull request with a screenshot of your template in both modes.

## Guidelines

- Use semantic HTML and keep contrast readable.
- Don't add trackers, analytics or external scripts.
- Keep pull requests focused on one change.
